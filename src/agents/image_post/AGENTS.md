# Image Post Agents

Image post is a formal content route, but its phases are specialist agents rather
than an independent end-to-end runner.

## Phases

- `research/`: researches the topic and produces structured `ResearchResult`.
- `content/`: turns research and grouping into Xiaohongshu-style copy.
- `image/`: computes groups when needed, builds image prompts, generates images, and validates image quality.
- `utils/`: image-post specific helpers for research cleanup, content feedback, grouping, and image specs.

## Boundaries

- Feishu orchestration is handled by `src/orchestration/image_route.py`.
- Image style is supplied through `StyleContext`, built from user constraints and repository Skills.
- Files generated by this route must be surfaced as `ArtifactRef` entries on a `ResultEnvelope`.
- Login support is available through `src/agents/shared/login` for research access only.
