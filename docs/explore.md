# 小红书内容选题探索方法论

> 本文档记录了 image_topics.json 选题的完整探索流程与方法论。
> 下一轮探索时直接从「第四步」开始，复用已有数据基线。

---

## 一、探索流程总览

```
第一步：运营数据分析（笔记列表明细表.xlsx）
    ↓
第二步：多Agent辩论（4个独立视角）
    ↓
第三步：小红书实地调研（Playwright 多路并发）
    ↓
第四步：紧急会议（3个审计Agent交叉验证）
    ↓
第五步：综合裁决 → 更新 image_topics.json
```

---

## 二、各步骤详细方法

### 第一步：运营数据分析

**输入文件：** `笔记列表明细表.xlsx`（从小红书创作者后台导出）

**分析维度：**

1. **分类打标** — 对每条笔记按标题关键词自动分类：
   - 黄黑皮/显白、小个子/显高、身材修饰/显瘦、拍照技巧、脸型/身体部位、收纳/旅行、美妆护肤、穿搭技巧(泛)、其他
   - 分类函数使用关键词匹配（见历史对话中的 `categorize()` 函数）

2. **各分类统计指标：**
   - 条数、平均曝光、平均收藏、互动率（(赞+藏+评+享)/曝光）、平均涨粉
   - 注意用**中位数**而非均值，避免被极端爆文拉偏

3. **标题模式分析：**
   - 数字清单型 vs 非清单型的曝光对比
   - 关键词效果：实测/避雷/公式/法则/攻略/必看 各自的曝光均值
   - Emoji 影响、感叹号/问号影响

4. **时间趋势：** 按月统计产量和曝光均值变化

5. **TOP/BOTTOM 排行：** 曝光最高20条和最低20条，找规律

**输出：** 各分类的表现排名 + 淘汰/保留/探索的初步判断

---

### 第二步：多Agent辩论

同时发起 **4个独立视角的 sub agent**，给每个agent相同的数据但不同的立场：

| Agent角色 | 核心立场 | 关注重点 |
|-----------|---------|---------|
| **增长最大化派** | 追强加码 | 哪些话题应该持续投入？加码策略？天花板预警？ |
| **蓝海探索派** | 拓展新方向 | 哪些相邻方向值得探索？如何低成本试水？哪些方向不适合？ |
| **风险分析师/淘汰官** | 冷酷裁决 | 哪些话题立即停止？资源浪费量化？隐藏风险？反直觉发现？ |
| **受众生命周期策略师** | 长期用户价值 | 受众画像？需求链条？内容矩阵分层？涨粉vs曝光矛盾？人设建议？ |

**关键：** 4个agent互不通信，独立产出，最终由人综合裁决。重点关注：
- 全员共识 → 直接执行
- 分歧点 → 需要进一步验证

---

### 第三步：小红书实地调研（Playwright）

用 Playwright 浏览器自动化，在小红书上做**多路并发搜索调研**。

**调研方法：**

1. 导航到 `https://www.xiaohongshu.com/search_result?keyword=关键词`
2. 对每个搜索页 take snapshot，记录：
   - **筛选标签栏**（平台算法自动生成，代表真实用户需求维度）
   - **内容标题 + 点赞数**（真实互动数据）
   - **"大家都在搜"推荐词**（用户真实搜索行为）
   - **内容发布时间**（判断是新趋势还是旧帖）

**同时发起3-4组调研Agent，每组负责不同维度：**

| 调研组 | 关键词生成方法 | 目的 |
|--------|-------------|------|
| **趋势调研组** | `穿搭+当前年份季节`、`最近很火的穿搭`、`穿搭灵感+当季` | 捕捉当前实时热点 |
| **竞品调研组** | 从第一步运营数据中提取**本账号TOP3品类关键词**，搜`关键词+博主/合集` | 看头部账号在同赛道做什么 |
| **蓝海验证组** | 从第二步辩论中提取**各Agent建议的新方向关键词** | 验证辩论中提出的新方向是否有真实市场 |
| **需求验证组** | 从第一步中提取**表现不确定的中间地带品类关键词** | 验证灰色地带话题的真实热度 |

**关键词生成规则（每轮动态生成，不写死）：**

1. **从运营数据中来：** 第一步分析后，提取TOP品类核心词（如曝光最高的3个分类名称）和BOTTOM品类词（用于确认是否该砍）
2. **从辩论结论中来：** 第二步4个Agent各自建议的新方向，都要上小红书搜一遍验证
3. **从平台自身来：** 第一轮搜索后，小红书的"大家都在搜"推荐词和筛选标签栏会暴露大量延伸关键词，用这些词做第二轮搜索（滚雪球式）
4. **从时间节点来：** 当前季节/节日/社会热点 + 穿搭（如换季、开学季、春招、618、年会）
5. **从上轮遗留来：** 上一轮探索中标记为"样本不足待验证"的方向

**本轮调研关键发现（作为下轮基线）：**

- **旧衣新穿是碾压级爆款**：桥豆麻袋5.9万赞，Miho!!!系列稳定3500-8400赞
- **体制内穿搭是真蓝海**：7243赞，平台有独立标签"厅局风""公务员"
- **老钱风是红海**：仍有高赞但竞争饱和，新号难突围
- **松弛感正在退潮**：2026新内容507赞，沦为万能标签
- **高智感是早期蓝海**：绑定通勤场景后7639赞，纯风格帖424赞
- **"不花钱变美"是最强底层情绪**：TOP4爆款全是旧衣改造
- **身份标签越具体越好**：月薪6K > 打工人 > 女生
- **平台热门风格标签**：老钱风(红海)、轻熟风(高频)、松弛感(退潮)、高智感(蓝海)、中性风(缺供给)、御姐风(有需求)

### 第四步：紧急会议（交叉验证）

基于实地调研数据，再发起 **3个审计Agent** 做交叉验证：

| Agent角色 | 审计内容 |
|-----------|---------|
| **数据真相官** | 逐条对比选题计划 vs 实地数据：哪些被验证？哪些被打脸？哪些低配/高配？ |
| **内容形式创新官** | 审计选题的标题模式和内容形式是否同质化，对比平台真实爆款的形式创新 |
| **受众盲区分析师** | 检查选题是否覆盖了平台上的真实受众需求图谱，找出遗漏的群体和需求 |

**本轮审计关键裁决（作为下轮起点）：**

| 裁决 | 内容 |
|------|------|
| 严重低配 | 旧衣新穿（3条→6条）、体制内（1条P2→3条P0） |
| 应砍方向 | 老钱风(红海)、松弛感(退潮)、清冷感(无数据)、旅行穿搭(历史互动65全品类倒数) |
| 形式同质化 | "数字+公式/避雷"从70%降到40%，加入挑战型/日记型/反差叙事型/反认知型 |
| 受众盲区 | 大码胖mm(非微胖)、轻熟风、中性风、00后初入职场、留学生 |
| 超级需求 | "不花钱变美"从16.7%提升到26.7% |

```json
}
```

## 四、探索原则（不要忘记）

1. **不要只追爆款** — 纯追强会撞天花板（预估35-40条后衰减），必须保留探索比例
2. **内容形式多元化** — "数字+公式/避雷"不超过40%，必须包含挑战型/日记型/反差型
3. **身份标签越具体越好** — "月薪6K" > "打工人" > "女生"
4. **用中位数而非均值** — 避免被极端爆文制造虚假乐观
5. **验证周期3-5条** — 每个新方向先试3条，互动率≥0.7%才加码
6. **"不花钱变美"是底层情绪** — 应渗透到所有选题中，不仅限于专门的省钱分类
7. **措辞合规** — 用"适合XX的版型"替代"遮肉"，用"身材友好"替代"显瘦"
8. **平台标签是金矿** — 搜索结果页的筛选标签栏是平台算法根据真实用户行为生成的，是最可靠的需求信号
