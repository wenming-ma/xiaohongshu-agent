# Reference Image Runtime Notes

- Each reference image should be labeled to an item or visual cue before generation.
- For a referenced item, preserve color, shape, texture, pattern, material, and distinctive construction details.
- Use phrasing like: `the item matches the exact appearance shown in its labeled reference photo, including color, shape, texture and design details`.
- The reference item can be repositioned or scaled for composition, but its visible identity should stay stable.
- Do not render reference images as screenshots, thumbnails, app windows, browser panels, or collage inserts.
- Do not include negative-review items unless the current group explicitly needs a warning/avoidance visual.
