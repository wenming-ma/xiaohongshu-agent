# Realistic Editorial Image Style

## Overview
Use this skill when an image post should feel like a real editorial photograph, lifestyle scene, product shot, outfit flatlay, travel image, food image, or magazine-style visual.

## Workflow
1. Choose the visual route from the subject: outfit, product, lifestyle, food, travel, scene, illustration, or information card.
2. Prefer concrete scene description over keyword piles.
3. Add believable camera, lens, light, texture, material, and natural imperfection details when using a photographic style.
4. Keep Chinese text short and intentional when text is needed.

## Style Rules
- For photographic images, describe a complete scene in natural language.
- Use real camera/lens cues only when they help: Sony A7IV, Canon EOS R5, Nikon Z9, Fujifilm X-T5, 50mm, 85mm, 35mm, macro lens.
- Add real-world texture: fabric weave, small wrinkles, soft shadows, dust motes, condensation, worn edges, natural light falloff.
- Prefer off-center, rule-of-thirds, or naturally arranged compositions over rigid symmetry.
- Avoid cold dashboard-style infographics unless the content truly needs a structured information card.

## Common Mistakes
- Making every image a phone/app workflow illustration.
- Using generic words like perfect, flawless, symmetrical, pristine, ultra-HD render, CGI, or studio render.
- Letting operational notes, source labels, usernames, or research diagnostics appear in the picture.
