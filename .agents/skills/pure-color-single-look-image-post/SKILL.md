# Pure Color Single-Look Image Post

## Overview
Use this skill when we want a tightly controlled outfit carousel: one look per frame, pure-color or near-solid background, low clutter, and clear pacing from cover to detail.

## When to Use
- User asks for `纯色背景`
- User asks for `每张图只放一套穿搭`
- We want the image route to feel editorial instead of collage-heavy
- The goal is high readability in Feishu review before later reuse

## Workflow
1. Keep research focused on silhouette, color pairing, fabric detail, and scene fit.
2. Group results by one visual idea per image. Do not pack multiple outfits into one frame.
3. Cover image should emphasize the strongest silhouette and color story.
4. Detail images should each carry one message only: fabric, styling logic, accessory balance, or proportion.

## Style Rules
- Background should stay solid, low-texture, or softly graded within one hue family.
- Avoid mixed environments, busy props, and multi-scene compositions.
- Keep text overlays minimal and readable.
- Maintain clear spacing so the user can scan quickly on mobile.
- If the user asks for flatlay/no model, show clothing and accessories arranged as a finished outfit on the surface. Do not introduce a mannequin or body unless the user explicitly asks.
- Treat every image as one visual job. Cover can set the strongest silhouette and color story; detail images should not repeat the cover composition with only tiny changes.

## Common Mistakes
- Treating the post like a collage and placing multiple outfits in one image.
- Using decorative props that overpower the outfit itself.
- Writing detail pages as if they were mini covers instead of focused explanations.
- Accidentally rendering operational artifacts such as app screens, login popups, research notes, or diagnostic cards.
