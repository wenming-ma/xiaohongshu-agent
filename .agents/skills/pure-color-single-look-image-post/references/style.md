# Pure Color Single-Look Runtime Notes

Use these notes when building `StyleContext` for pure-color outfit image posts.

- Use a pure-color, near-solid, or softly graded background in one hue family.
- Put exactly one outfit/look in each frame. For flatlay requests, arrange garments and accessories as a complete outfit on the surface.
- Avoid people, models, mannequins, app screenshots, login dialogs, research limitations, tool errors, and diagnostic cards unless the user explicitly asks for them.
- Keep cover and detail images visually distinct: cover sells the strongest silhouette or palette; each detail frame carries one styling idea only.
- Prefer clean editorial spacing, visible fabric texture, believable shadows, and restrained props.
- Keep text overlays minimal. If text is necessary, use short simplified Chinese phrases only.
