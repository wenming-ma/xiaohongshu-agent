# Collage Moodboard Poster

## Use When
Use when the user asks for a moodboard, visual direction board, style board, or
inspiration collage.

## Constraints
- Use a cohesive palette and visual logic, not random scrapbook clutter.
- Avoid copyrighted magazine scans, brand logos, and fake handwritten text.
- Keep the board's elements traceable to the current topic or style context.

## Prompt Template
Generate a cohesive moodboard-style 3:4 image for `{theme}` using curated
objects, textures, color swatches, small scene fragments, and material samples.
Use a clean editorial layout with clear spacing and a consistent visual mood.
