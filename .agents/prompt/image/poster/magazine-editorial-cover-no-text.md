# Magazine Editorial Cover No Text

## Use When
Use when a cover should feel like a premium magazine editorial image but the
workflow should avoid generated fake text.

## Constraints
- No fake masthead, captions, subtitles, barcodes, or issue numbers.
- Use composition, styling, light, and negative space to create cover energy.
- Keep the subject tied to the current group and route plan.

## Prompt Template
Generate a 3:4 magazine-style editorial cover image of `{subject}` with strong
visual hierarchy, refined styling, premium lighting, and intentional negative
space. Keep the image text-free and suitable for adding real copy later.
