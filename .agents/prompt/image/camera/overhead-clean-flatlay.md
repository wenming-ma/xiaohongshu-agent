# Overhead Clean Flatlay

## Use When
Use when the image should present products, outfits, tools, food, or travel
objects as an organized top-down arrangement.

## Constraints
- Keep the camera exactly overhead unless the current group asks for a different
  angle.
- Arrange only objects from the current group and user constraints.
- Leave enough negative space for mobile-feed readability, but do not add fake
  labels, UI panels, login screens, or decorative arrows.

## Prompt Template
Generate a 3:4 vertical overhead flatlay of `{group_subject}`. Arrange the
selected objects as a believable real-world set on `{background_surface}` with
clear spacing, subtle shadows, visible material texture, and a calm Xiaohongshu
editorial rhythm. Keep the composition object-led, text-free, and directly
related to the current group.
