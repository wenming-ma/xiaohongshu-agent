# Multi-Angle Reference Set

## Use When
Use when the user needs a compact visual set showing the same subject from
several practical angles for review or comparison.

## Constraints
- Keep the same subject identity, color, and material across all views.
- Use a clean layout without fake technical labels unless exact text is
  explicitly provided.
- Do not turn the set into an unrelated collage of different products.

## Prompt Template
Generate a single 3:4 image containing `{subject}` shown in three consistent
angles: front, three-quarter, and close detail. Keep each view visually aligned,
same lighting, same color, same material finish, and enough spacing that the
viewer can compare the subject without confusion.
