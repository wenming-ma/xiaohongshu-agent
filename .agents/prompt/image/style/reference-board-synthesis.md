# Reference Board Synthesis

## Use When

Use when multiple reference images or style notes need to become one coherent
image-generation direction.

## Constraints

- Separate must-match details from mood-only inspiration.
- Resolve conflicts by following user constraints first.
- Do not merge unrelated products into one impossible object.
- Keep final instruction short enough for image models.

## Prompt Template

Synthesize `{reference_board}` into image guidance.

Return:
- Must-match visual anchors.
- Optional mood cues.
- Composition recommendation.
- Negative constraints.
- Final compact image prompt addendum.
