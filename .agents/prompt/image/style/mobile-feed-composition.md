# Mobile Feed Composition

## Use When

Use when an image must perform well in a vertical Xiaohongshu or Feishu review
context.

## Constraints

- Prioritize first-glance clarity.
- Leave breathing room around the subject.
- Avoid tiny details that only work on desktop.
- Do not overuse text overlays.

## Prompt Template

Compose `{image_subject}` for a mobile vertical feed.

Use:
- Clear focal point in the upper-middle area.
- Supporting details arranged with readable rhythm.
- Background that reinforces style without stealing attention.
- High contrast between subject and background.
- No irrelevant UI or documentation artifacts.
