# Clean Knowledge Card

## Use When
Use for knowledge summaries, checklists, comparison cards, step-by-step
explainers, or article-derived image cards.

## Constraints
- Use simplified Chinese if text is needed.
- Keep text short, legible, and tied to the current group.
- Avoid screenshots, login prompts, internal research notes, or model
  limitation messages.

## Prompt Template
Create a 3:4 vertical Xiaohongshu knowledge card with a clean editorial layout.
Use one main takeaway, concise Chinese text blocks, subtle icons only when
helpful, and generous spacing. Keep the visual hierarchy clear and avoid dense
PowerPoint-style clutter.
