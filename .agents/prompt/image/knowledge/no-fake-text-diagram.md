# No-Fake-Text Diagram

## Use When

Use when a knowledge image should be visual, but generated text would likely be
wrong or distracting.

## Constraints

- Communicate with shapes, objects, arrows, spacing, or color blocks.
- Avoid readable fake Chinese or English text.
- If labels are needed, keep them for post-production, not image generation.
- Keep layout clean and mobile-readable.

## Prompt Template

Create a text-free explanatory visual for `{knowledge_topic}`.

Use:
- Visual metaphor: `{visual_metaphor}`.
- Layout: `{diagram_layout}`.
- Color palette: `{palette}`.
- No generated text, fake UI, screenshots, or research cards.
- Leave clean space for later manual labels if needed.
