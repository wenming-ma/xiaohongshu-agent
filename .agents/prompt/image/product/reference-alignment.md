# Product Reference Alignment

## Use When
Use when reference images or product appearance constraints must be preserved
for clothing, accessories, skincare, cosmetics, home goods, or gadgets.

## Constraints
- Preserve the referenced silhouette, color, material, and recognizable product
  structure.
- Do not invent major new product features.
- Mute or avoid brand names unless the user explicitly requires them.

## Prompt Template
Generate a clean 3:4 product editorial image that follows the provided reference
appearance. Match the product's shape, proportions, material, color, and key
details while placing it in a refined Xiaohongshu composition with controlled
lighting and minimal distractions.
