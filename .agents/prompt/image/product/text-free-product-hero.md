# Text-Free Product Hero

## Use When

Use for product-centered images where the visual should communicate through
object styling, not generated text.

## Constraints

- Avoid readable text, fake labels, charts, UI panels, and slogans.
- Emphasize product material, shape, color, scale, and context.
- Keep composition clean enough for Xiaohongshu mobile feed.
- If reference images exist, preserve key product appearance.

## Prompt Template

Create a vertical product hero image for `{product_or_topic}`.

Visual direction:
- Main object: `{required_product_details}`.
- Scene: `{scene_context}`.
- Style: `{style_context}`.
- No generated text or fake UI.
- Output should feel like editorial product photography.
