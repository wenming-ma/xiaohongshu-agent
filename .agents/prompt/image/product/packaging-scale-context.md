# Packaging Scale Context

## Use When

Use when product scale, size, or everyday usability matters.

## Constraints

- Use neutral scale cues like shelf, pouch, book, cup, or tabletop grid.
- Avoid hands if the user requested no people.
- Do not distort packaging proportions.
- Keep scale cue secondary to the product.

## Prompt Template

Show `{product_subject}` with scale context.

Use:
- Scale cue: `{scale_reference}`.
- Product placement: clear and front-readable but no fake text.
- Background: `{background_style}`.
- Lighting: `{lighting_style}`.
- No clutter, UI, or unrelated props.
