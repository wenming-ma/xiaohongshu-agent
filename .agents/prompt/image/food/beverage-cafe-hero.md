# Beverage Cafe Hero

## Use When

Use for coffee, tea, juice, cocktails, or cafe drink images that need a single
strong hero composition.

## Constraints

- One drink is the hero.
- Avoid impossible foam art unless requested.
- Keep background cafe cues subtle.
- Do not add fake brand labels or menus.

## Prompt Template

Create a cafe beverage hero image for `{drink_subject}`.

Use:
- Hero drink: `{drink_details}`.
- Setting: `{cafe_context}`.
- Light: `{lighting_style}`.
- Props: `{supporting_props}`.
- Composition: vertical mobile editorial.
