# Carousel Sequence Rhythm

## Use When

Use when several images should feel like one Xiaohongshu carousel instead of
unrelated standalone generations.

## Constraints

- Define what changes and what stays consistent across images.
- Avoid repeating identical composition.
- Preserve color, lighting, and prop language.
- Match each image to its own group content.

## Prompt Template

Create image `{sequence_index}` of `{sequence_total}` for `{topic}`.

Sequence rules:
- Consistent: `{shared_visual_language}`.
- This image focus: `{group_content}`.
- Composition variation: `{composition_role}`.
- Avoid: unrelated scenes, app screenshots, fake research cards.
