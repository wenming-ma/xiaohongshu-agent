# Flatlay Grid Composition

## Use When

Use for outfits, product kits, travel packing, food ingredients, or desk setups
that need a clear overhead arrangement.

## Constraints

- Use one visual theme per image.
- Keep spacing intentional and mobile-readable.
- Avoid random filler props.
- Do not show app UI, screenshots, or text panels.

## Prompt Template

Create an overhead flatlay grid for `{image_subject}`.

Include:
- Main objects: `{visual_anchors}`.
- Background: `{background_style}`.
- Layout: balanced grid with breathing room.
- Lighting: `{lighting_style}`.
- Exclusions: `{negative_constraints}`.
