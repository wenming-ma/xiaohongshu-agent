# No-Model Outfit Board

## Use When

Use when the user explicitly asks for outfit images without people, models, or
mannequins.

## Constraints

- No bodies, faces, hands, mannequins, hangers shaped like bodies, or mirror
  selfies.
- Clothes must be visually arranged as a complete outfit.
- Background should be simple and intentional.
- One look per image unless user requests a comparison.

## Prompt Template

Create a no-model outfit board for `{outfit_theme}`.

Show:
- Clothing: `{clothing_items}`.
- Shoes and accessories: `{accessories}`.
- Background: `{background_style}`.
- Composition: flatlay or neatly arranged product board.
- Exclude people, mannequins, fake text, and app UI.
