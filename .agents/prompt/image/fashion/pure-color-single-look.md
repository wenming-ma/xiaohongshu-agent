# Pure Color Single Look Fashion Image

## Use When
Use for outfit image posts where each image should show one complete look on a
pure or near-solid background, with no model and no mannequin.

## Constraints
- Show exactly one outfit or one coherent clothing set per image.
- Keep the background flat, clean, and clearly separated from the garments.
- Avoid app UI, login screens, diagnostic cards, unrelated icons, and fake text.
- Keep accessories secondary; they should support the outfit, not become clutter.

## Prompt Template
Create a vertical 3:4 Xiaohongshu-ready fashion flat-lay image. Present one
complete outfit arranged neatly on a pure-color background. Emphasize silhouette,
fabric texture, color harmony, and spacing. The image should feel like a premium
editorial styling board, not an infographic.
