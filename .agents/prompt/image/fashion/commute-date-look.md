# Commute Date Outfit Editorial

## Use When
Use for city commute, interview, date, cafe, weekend, or soft formal outfit
scenes where the user wants polished but wearable styling.

## Constraints
- Keep the outfit approachable and suitable for the stated audience.
- Avoid luxury-logo emphasis, fake brand names, and excessive accessories.
- If no model is requested, use flat-lay or hanger styling.

## Prompt Template
Create a refined 3:4 vertical outfit editorial. Style one complete city-ready
look with soft lighting, controlled negative space, and a clear color story.
Make the clothing feel tactile and wearable, with subtle detail on fabric,
buttons, seams, shoes, and bag proportions.
