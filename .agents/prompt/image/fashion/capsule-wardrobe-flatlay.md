# Capsule Wardrobe Flatlay

## Use When

Use for capsule wardrobe, commute outfits, travel packing, or "one item many
looks" image groups.

## Constraints

- Keep each outfit coherent and wearable.
- Do not overcrowd the frame.
- Labeling should be absent unless explicitly requested.
- Maintain a consistent color palette across carousel images.

## Prompt Template

Create a capsule wardrobe flatlay for `{scenario}`.

Include:
- Core pieces: `{clothing_items}`.
- Accessories: `{accessories}`.
- Background: `{background_style}`.
- Style mood: `{style_context}`.
- One complete look, no model, no mannequin.
