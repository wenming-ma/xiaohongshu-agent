# Outdoor Functional Flatlay

## Use When
Use for hiking, camping, trail, snow, rain, or outdoor commute outfit groups.

## Constraints
- Keep the look practical and physically plausible for the named scene.
- Include only items from the current group; do not mix in unrelated food,
  cosmetics, phones, or login/tool symbols.
- Avoid human bodies unless the current request explicitly asks for models.

## Prompt Template
Generate a 3:4 vertical outdoor gear flat-lay on a restrained natural-color
background. Arrange the jacket, base layer, pants, shoes, and small accessories
as one functional set. Show fabric weight, waterproof texture, soles, buckles,
and useful outdoor details with clean editorial lighting.
