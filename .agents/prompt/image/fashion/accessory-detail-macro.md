# Accessory Detail Macro

## Use When

Use for shoes, bags, jewelry, belts, sunglasses, or material closeups in a
fashion carousel.

## Constraints

- Keep accessory connected to the current outfit story.
- Avoid luxury-logo hallucination.
- Show scale through nearby garment texture or surface, not hands unless
  requested.
- Do not add unrelated makeup or tech items.

## Prompt Template

Create a macro accessory detail image for `{accessory_subject}`.

Focus:
- Material: `{material_detail}`.
- Outfit relation: `{outfit_context}`.
- Surface: `{surface_style}`.
- Lighting: `{lighting_style}`.
- No fake brand logos, UI, or text.
