# Bundle Layout Comparison

## Use When
Use for curated kits, outfit formulas, product bundles, capsule wardrobes,
travel packing sets, or option comparisons.

## Constraints
- Keep each bundle visually separated and equally readable.
- Do not imply fake pricing, rankings, or brand claims unless provided.
- Use only objects from the current groups.

## Prompt Template
Generate a clean comparison layout of `{bundle_count}` curated bundles for
`{topic}`. Give each bundle its own visual zone with consistent camera angle,
clear spacing, matching lighting, and enough detail for users to compare the
sets at a glance.
