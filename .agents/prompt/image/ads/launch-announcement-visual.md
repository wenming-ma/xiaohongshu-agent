# Launch Announcement Visual

## Use When
Use for new collection, seasonal update, event teaser, limited set, or feature
announcement visuals where the subject should feel fresh but not like a poster
full of text.

## Constraints
- Keep text optional and minimal; exact text must come from the user or content
  Agent.
- Make the announcement feel visual-first.
- Avoid fake countdowns, badges, QR codes, app screens, or unsupported claims.

## Prompt Template
Generate a visual-first launch announcement image for `{launch_subject}` with
fresh composition, confident negative space, a clear hero object, and subtle
seasonal or event cues. If text is allowed, include only `{provided_text}` as a
small clean title area.
