# Social Commerce Hero

## Use When
Use for Xiaohongshu-style commercial or recommendation covers where one product,
outfit, destination, dish, or object needs immediate feed impact.

## Constraints
- Keep the hero subject dominant and readable in a mobile crop.
- Use visual hierarchy through scale, light, color, and negative space instead
  of fake UI banners.
- Avoid exaggerated medical, financial, or guaranteed-effect claims.

## Prompt Template
Generate a 3:4 social-commerce hero image for `{subject}`. Use one strong focal
subject, clean composition, premium lighting, and a simple supporting scene that
communicates `{benefit_or_mood}` without relying on heavy text or app-like
graphics.
