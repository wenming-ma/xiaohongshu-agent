# Scene Editorial

## Use When

Use for lifestyle scenes where the image should feel photographic, lived-in,
and emotionally specific.

## Constraints

- Anchor the scene in a real moment, not a generic stock-photo tableau.
- Avoid clutter, brand names, fake UI, and unrelated props.
- If people appear, keep expression natural and energetic.
- Match the user's audience and route constraints.

## Prompt Template

Generate an editorial lifestyle scene for `{topic}`.

Include:
- Moment: `{scene_moment}`.
- Key objects or outfit details: `{visual_anchors}`.
- Mood: `{style_context}`.
- Composition: mobile-first vertical frame.
- Exclusions: `{negative_constraints}`.
