# Paper Card Print Texture

## Use When
Use for stationery, printed cards, recipe cards, packaging inserts, note cards,
or editorial paper objects.

## Constraints
- Do not create illegible fake body text unless the exact text is supplied.
- Emphasize paper texture, print finish, edge thickness, and shadows.
- Keep the layout free of app UI or login-style forms.

## Prompt Template
Generate a tactile paper-card still life for `{paper_subject}` with visible
paper grain, slight edge thickness, soft shadow, restrained print details, and
clean composition. If text is needed, use only `{provided_text}` and keep it
large, minimal, and readable.
