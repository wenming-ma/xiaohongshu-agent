# Textile Fabric Weave

## Use When
Use for clothing, bags, bedding, towels, outdoor gear, knitwear, denim, linen,
wool, or any image where textile quality should carry the visual.

## Constraints
- Show fabric weave, thickness, drape, seams, and edge details.
- Do not turn fabric into plastic or overly smooth synthetic surfaces.
- Preserve the garment or object structure from the current group.

## Prompt Template
Generate a textile-focused image of `{garment_or_fabric}` showing weave,
drape, stitching, seams, folds, and subtle wear. Use natural directional light
and a restrained background so the material quality becomes the main reason to
save the image.
