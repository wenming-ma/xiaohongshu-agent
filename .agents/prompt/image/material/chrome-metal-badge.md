# Chrome Metal Badge

## Use When
Use for premium icons, badges, accessories, hardware, metallic packaging, or
small objects that need a polished reflective finish.

## Constraints
- Keep the metal object readable and avoid mirror reflections that create
  confusing shapes.
- Use restrained highlights, not noisy glitter.
- Do not add slogans, brand marks, or text unless explicitly provided.

## Prompt Template
Generate a premium chrome-metal visual of `{subject}` with smooth rounded edges,
clean reflections, subtle bevels, controlled studio lighting, and a simple
surface shadow. The result should feel tactile, collectible, and high-end.
