# Outfit Reference Translation

## Use When

Use when clothing reference images need to become a new outfit layout or scene
without changing garment identity.

## Constraints

- Preserve garment category, color, fabric, and key details.
- Do not add a mannequin or model unless requested.
- Keep one look per image when requested.
- Avoid mixing unrelated garments from different groups.

## Prompt Template

Translate outfit references into `{target_layout}`.

Preserve:
- Tops: `{top_details}`.
- Bottoms: `{bottom_details}`.
- Shoes/accessories: `{accessory_details}`.
- Layout: `{composition_style}`.
- Background: `{background_style}`.
