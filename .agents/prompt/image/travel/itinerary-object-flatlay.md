# Itinerary Object Flatlay

## Use When

Use for travel routes, camping plans, citywalk notes, or packing lists without
needing people.

## Constraints

- Objects should represent the itinerary clearly.
- Avoid fake maps with readable wrong place names.
- Keep props regionally plausible.
- Do not overcrowd the layout.

## Prompt Template

Create a travel itinerary object flatlay for `{destination_or_scene}`.

Include:
- Objects: `{travel_objects}`.
- Mood: `{style_context}`.
- Background: `{background_style}`.
- Composition: clean overhead or angled tabletop.
- No fake map labels, UI, or unrelated icons.
