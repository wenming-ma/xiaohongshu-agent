# No Unrelated Stock Icons

## Use When
Use when image prompts risk becoming generic infographic art with icons that do
not belong to the user's topic.

## Constraints
- Avoid stock magnifying glasses, phones, arrows, exclamation marks, plants,
  clouds, graphs, folders, generic avatars, and abstract UI shapes unless they
  are genuinely part of the requested subject.
- Prefer real objects, scenes, materials, and compositions.
- Keep every visible prop explainable from the current group.

## Prompt Template
Negative guard for `{subject}`: do not add generic stock icons, decorative
arrows, phone-login illustrations, random plants, alert symbols, browser cards,
or unrelated props. Every object in the image must support the current content
group.
