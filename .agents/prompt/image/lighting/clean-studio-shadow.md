# Clean Studio Shadow

## Use When

Use for pure-color backgrounds, product arrangements, and outfit flatlays that
need simple but not flat lighting.

## Constraints

- Background should be plain but not dead.
- Include a natural contact shadow.
- Avoid fake gradients that distract from the subject.
- Keep color palette controlled.

## Prompt Template

Place `{image_subject}` on a clean studio background.

Lighting:
- One softbox-like key light.
- Gentle contact shadows.
- Background color: `{background_color}`.
- Material rendering: `{material_detail}`.
- No text, UI, or diagnostic graphics.
