# Soft Window Light

## Use When

Use for realistic editorial images that should feel natural, warm, and
approachable.

## Constraints

- Light should come from one believable window direction.
- Preserve soft shadows and real surface texture.
- Avoid overexposed white backgrounds.
- Do not add studio gear unless requested.

## Prompt Template

Light `{image_subject}` with soft window light.

Details:
- Direction: side light from `{light_direction}`.
- Shadow: soft, visible, natural.
- Color temperature: `{color_temperature}`.
- Surface: `{surface_material}`.
- Mood: quiet editorial realism.
