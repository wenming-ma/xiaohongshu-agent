# Photographic Cover No Text

## Use When

Use for cover images where typography will be added later or the model should
not generate text.

## Constraints

- Create a strong first-glance visual hook without text.
- Leave optional title-safe space.
- Keep subject and theme obvious.
- Avoid generic icons and phone mockups.

## Prompt Template

- Hero visual: `{hero_visual}`.
- Background: `{background_style}`.
- Style: `{style_context}`.
- Optional title-safe negative space.
- No generated words, UI screens, or research-note cards.
