# Xiaohongshu Cover Hook Image

## Use When
Use for cover images that need a strong hook and immediate topic clarity.

## Constraints
- The cover must match the actual post content, not bait-and-switch.
- Keep text brief and readable on mobile.
- Avoid overpromising outcomes or medical/financial certainty.

## Prompt Template
Generate a 3:4 vertical Xiaohongshu cover image. Build one strong focal visual
from the post topic, with a concise simplified-Chinese hook headline and clean
supporting composition. Make the cover visually distinct from detail images.
