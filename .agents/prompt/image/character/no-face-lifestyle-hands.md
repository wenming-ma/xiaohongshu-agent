# No-Face Lifestyle Hands

## Use When
Use when the scene needs human presence for scale or usage but the user does
not want visible faces, models, or identity-heavy portraits.

## Constraints
- Show only hands, partial arms, or cropped body details when needed.
- Keep the product, outfit, food, or object as the focus.
- Avoid unrealistic hands, extra fingers, face fragments, or model poses.

## Prompt Template
Generate a no-face lifestyle image of `{subject}` being used or arranged in
`{scene}`. Include only natural hands or cropped body details if needed for
scale, with realistic skin, correct anatomy, and the main object clearly
visible.
