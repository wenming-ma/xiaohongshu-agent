# Illustrated Avatar Consistent

## Use When
Use when a recurring illustrated character, guide, or avatar is useful for a
series of images or educational content.

## Constraints
- Preserve the same avatar design across variations.
- Avoid copying existing cartoon or celebrity styles.
- Keep the avatar secondary if the content requires product or knowledge focus.

## Prompt Template
Generate an original illustrated avatar for `{topic}` with consistent clothing,
palette, proportions, and expression style. Place the avatar in a simple scene
that supports `{content_point}` without overpowering the main information.
