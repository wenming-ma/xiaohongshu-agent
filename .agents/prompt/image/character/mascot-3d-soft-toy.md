# Mascot 3D Soft Toy

## Use When
Use for playful brand mascots, cute explanatory objects, cozy collectibles, or
soft-toy style visuals.

## Constraints
- Keep the mascot concept tied to the topic and not randomly cute.
- Avoid using protected characters or recognizable IP unless the user owns it.
- Do not add text labels unless exact copy is supplied.

## Prompt Template
Generate a soft 3D mascot toy inspired by `{topic_symbol}` with plush texture,
rounded proportions, gentle expression, tactile seams, and a clean studio scene.
The mascot should communicate `{mood_or_message}` while remaining original.
