# Colorway Variant Control

## Use When
Use when the user asks for color variants while preserving the same product,
outfit, accessory, room, package, or object design.

## Constraints
- Only change the requested colorway or palette.
- Keep shape, material, pattern scale, hardware, stitching, and layout stable.
- Do not invent extra variants beyond the requested count.

## Prompt Template
Generate `{variant_count}` colorway variants of `{subject}` in one cohesive
3:4 image. Keep the same design, silhouette, material, details, and lighting
across all variants while changing only the palette to `{palette_direction}`.
