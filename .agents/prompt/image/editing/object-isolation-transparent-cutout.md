# Object Isolation Transparent Cutout

## Use When
Use when a product, clothing item, accessory, prop, or ingredient needs to be
isolated for later layout, carousel composition, or Feishu review.

## Constraints
- Keep the cutout clean and complete, including small straps, handles, laces,
  labels, or edges that belong to the object.
- Do not add background scenery, text, UI, hands, or mockup frames.
- If transparency is not supported by the image model, use a plain neutral
  background and state that the output should be easy to mask.

## Prompt Template
Generate a clean isolated cutout of `{subject}` with full object visibility,
accurate edges, neutral lighting, and no background clutter. Keep the object
centered with enough margin for later composition and preserve its true material
and color.
