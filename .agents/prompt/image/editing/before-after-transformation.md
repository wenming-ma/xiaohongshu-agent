# Before After Transformation

## Use When
Use for comparison images showing styling change, cleaning, organization,
routine effect, setup upgrade, or visual transformation.

## Constraints
- Make the before and after halves visually comparable with matching camera
  angle and object scale.
- Avoid fake claims or impossible transformations.
- Do not insert diagnostic text or app UI panels.

## Prompt Template
Generate a clean two-panel 3:4 comparison image for `{transformation_topic}`.
Show the before state on the left and after state on the right with consistent
camera angle, lighting, scale, and object identity. Use visual contrast through
organization, texture, color, and clarity rather than excessive labels.
