# Background Replacement Clean Studio

## Use When
Use when the subject is already defined and only the environment should become
cleaner, more premium, or more Xiaohongshu-friendly.

## Constraints
- Preserve the subject exactly; do not redraw or alter important features.
- Replace only the background and supporting surface.
- Keep shadows and contact points realistic so the subject does not float.

## Prompt Template
Place `{subject}` in a clean studio setting with `{background_color_or_surface}`.
Preserve the subject identity, color, material, proportions, and pose. Add
natural contact shadows, soft reflections if appropriate, and a refined mobile
composition with no extra unrelated objects.
