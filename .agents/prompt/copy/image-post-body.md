# Image Post Body Copy

## Use When
Use for image post body text that explains generated image groups and gives the
viewer a reason to save or share.

## Constraints
- The body must match the generated images and grouping result.
- Do not mention internal agent steps, prompt templates, or model limitations.
- Keep the tone useful, warm, and not overproduced.

## Prompt Template
Write a Xiaohongshu image-post body with a short opening, grouped bullet points,
and a concise closing save/share cue. Mention each image group's practical
value, keep wording specific, and avoid generic lifestyle filler.
