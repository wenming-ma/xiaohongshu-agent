# Hook Angle Ladder

## Use When

Use when the first line or title needs stronger hooks without becoming clickbait.

## Constraints

- Build from concrete audience tension.
- Avoid fearmongering, fake urgency, and impossible claims.
- Make each hook visually compatible with the generated images.
- Keep options short enough for mobile scanning.

## Prompt Template

Create a hook ladder for `{topic}` and `{audience}`.

Levels:
- Direct practical hook.
- Scene-based hook.
- Contrarian but safe hook.
- Checklist hook.
- Soft emotional hook.
