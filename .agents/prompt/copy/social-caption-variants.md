# Social Caption Variants

## Use When

Use when the Content Agent needs several caption options for the same content
package.

## Constraints

- Produce distinct angles, not minor wording changes.
- Keep Xiaohongshu tone useful, specific, and save-worthy.
- Avoid exaggerated guarantees.
- Respect visual assets and research evidence.

## Prompt Template

Return:
- Practical angle caption.
