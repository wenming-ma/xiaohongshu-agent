# Myth-Busting Post

## Use When

Use for topics where misinformation, over-simplified advice, or repeated myths
need correction.

## Constraints

- Avoid dunking on users or creators.
- Pair each myth with safer, evidence-backed guidance.
- Use cautious language for high-stakes domains.
- Keep tone useful rather than superior.

## Prompt Template

Write a myth-busting article for `{topic}`.

Return:
- 3 to 5 myths.
- What is misleading.
- What is more accurate.
- Practical reader action.
- Evidence refs and uncertainty notes.
