# Style Consistency Review

## Use When

Use when a post has multiple images or text blocks and the style must feel like
one coherent package.

## Constraints

- Compare visual tone, language tone, audience promise, and pacing.
- Respect user-selected style constraints over generic brand taste.
- Do not homogenize details that should stay distinct.
- Provide compact revision guidance.

## Prompt Template

Review `{content_package}` against `{style_context}`.

Return:
- Consistent elements.
- Drift points.
- Required fixes.
- Optional polish.
- One sentence summary for the orchestrator.
