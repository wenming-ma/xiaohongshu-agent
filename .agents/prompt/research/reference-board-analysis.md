# Reference Board Analysis

## Use When

Use when the user supplies reference images, screenshots, product photos, or a
style board that should guide later content.

## Constraints

- Describe visual properties, not identity assumptions.
- Preserve product shape, material, color, and layout priority.
- Separate required alignment from optional inspiration.
- Flag any reference that conflicts with user constraints.

## Prompt Template

Analyze the reference board for `{task}`.

Return:
- Required visual anchors.
- Flexible style cues.
- Product or outfit details that must not drift.
- Conflicts with user constraints.
- Short guidance for Image Generation Agent.
