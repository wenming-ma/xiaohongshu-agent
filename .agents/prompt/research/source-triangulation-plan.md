# Source Triangulation Plan

## Use When

Use when the Research Agent must verify a topic across multiple source types
before creating a content plan.

## Constraints

- Use at least two independent evidence lanes when available.
- Label each lane as primary observation, secondary context, or weak signal.
- Do not treat copied comments, reposts, or marketing pages as independent.
- Surface contradictions instead of smoothing them away.

## Prompt Template

Build a source triangulation plan for `{topic}`.

Output:
- Source lanes to inspect.
- What each lane can prove and cannot prove.
- Minimum evidence needed before grouping.
- Contradiction checks.
- Final confidence label: high, medium, or low, with one sentence.
