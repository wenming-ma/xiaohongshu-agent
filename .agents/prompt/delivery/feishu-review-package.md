# Feishu Review Package

## Use When
Use when packaging final content for Feishu as the formal review and delivery
endpoint.

## Constraints
- Do not describe the package as already published to another platform.
- Include artifact references and review notes.
- Keep the summary easy to scan in a chat window.

## Prompt Template
Prepare a Feishu delivery package with title, route, summary, body copy,
artifact list, generation notes, risk notes, and recommended next actions. Keep
the output concise enough for chat review while preserving enough detail for
manual approval.
