# Delivery Risk Checklist

## Use When
Use before sending a final delivery package to Feishu or when reviewing generated
images and copy for obvious failures.

## Constraints
- Flag unrelated images, login screenshots, research limitation cards, fake UI,
  unsupported claims, and brand/privacy risks.
- Do not block delivery for stylistic preference unless it contradicts the user.
- Keep remediation specific.

## Prompt Template
Review the delivery package for relevance, visual consistency, user constraints,
claim safety, artifact completeness, and Feishu readability. Return pass/fail
status, concrete issues, and the smallest next fix for each issue.
