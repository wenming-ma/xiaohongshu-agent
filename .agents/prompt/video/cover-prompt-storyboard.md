# Video Cover Storyboard

## Use When
Use for video cover generation, thumbnail planning, or cover prompt creation.

## Constraints
- The cover must represent the actual video idea.
- Avoid dense text and fake app screenshots.
- Keep one strong visual subject.

## Prompt Template
Create a video cover storyboard with one main subject, simplified-Chinese hook
text, background mood, lighting, and composition. Include a compact image
generation prompt that can be passed to the cover/image Agent.
