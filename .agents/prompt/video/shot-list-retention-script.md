# Shot List Retention Script

## Use When

Use when converting research or grouping output into a short video plan.

## Constraints

- Every shot must justify attention in the first 3 seconds or deepen the story.
- Avoid vague b-roll.
- Keep visual action matched to narration.
- Use captions only when they improve comprehension.

## Prompt Template

Create a retention-focused shot list for `{topic}`.

Return:
- 0 to 3 second hook shot.
- Main sequence shots with purpose.
- Voiceover line per shot.
- Caption guidance.
- Ending action or save prompt.
